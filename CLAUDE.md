# CLAUDE.md — Polaroid

Native macOS SwiftUI app that turns screenshots into styled Polaroid frames with a
develop animation, handwritten captions, and one-click export. Targets the Mac App
Store as a one-time purchase.

## Project facts

- Language / UI: Swift 6 (`SWIFT_STRICT_CONCURRENCY: complete`), SwiftUI + AppKit, `@Observable` state.
- Min OS: macOS 14.0. Universal binary (`x86_64 arm64`).
- Bundle ID: `com.nosleeplab.Polaroid`. Marketing version is driven by `MARKETING_VERSION` in `project.yml`.
- Build system: XcodeGen. `project.yml` is the single source of truth — the `.xcodeproj`
  AND `Polaroid/Resources/Info.plist` are GENERATED artifacts. Do not hand-edit either;
  edit `project.yml` and re-run `xcodegen generate`. (`Info.plist` keys live under the
  target's `info.properties` block.)
- No third-party dependencies. No network calls. Fully sandboxed.

## Layout

- `Polaroid/Core/` — rendering + services: `PolaroidRenderer` (Core Graphics frame
  compositor), `PaperTextureGenerator` (+ `PaperTextureStore`), `ExportService`
  (PNG/save/copy/share), `ScreenshotWatcher` (DispatchSource Desktop watcher),
  `DevelopAnimation` (timing constants).
- `Polaroid/Models/` — `PolaroidDocumentModel` (the `@MainActor @Observable` app state /
  controller), `AppSettings` (UserDefaults-backed prefs), `PolaroidStyle` (+ all style
  enums), `Screenshot` / `RecentPolaroid`.
- `Polaroid/Views/` — SwiftUI views (`ContentView`, `PolaroidView`, `DropZoneView`,
  `CaptionEditor`, `StylePickerView`, `SettingsView`, `MenuBarContent`).
- `PolaroidTests/` — XCTest unit tests.
- `AppStore/` — `metadata.md` (listing copy), `generate_screenshots.swift` (deterministic
  2880×1800 marketing screenshot generator), `Screenshots/` (generated output).

## Build & run

```bash
brew install xcodegen          # one time
xcodegen generate              # regenerate Polaroid.xcodeproj + Info.plist from project.yml
open Polaroid.xcodeproj         # then Cmd+R on the Polaroid scheme
```

Terminal build (no signing, for CI / local verification):

```bash
xcodebuild -project Polaroid.xcodeproj -scheme Polaroid \
  -configuration Release -destination 'platform=macOS,arch=arm64' \
  CODE_SIGNING_ALLOWED=NO build
```

## Verify

```bash
xcodebuild -project Polaroid.xcodeproj -scheme Polaroid \
  -destination 'platform=macOS,arch=arm64' CODE_SIGNING_ALLOWED=NO test     # 21 tests
xcodebuild -project Polaroid.xcodeproj -scheme Polaroid \
  -configuration Release -destination 'platform=macOS,arch=arm64' analyze   # static analysis
swift AppStore/generate_screenshots.swift                                   # regenerate screenshots
```

## App Store submission (needs Mark's Apple account)

1. In `project.yml` bump `MARKETING_VERSION` (and `CURRENT_PROJECT_VERSION` per upload), `xcodegen generate`.
2. Open in Xcode, set the Apple Developer Team (Automatic signing), destination "Any Mac".
3. Product ▸ Archive ▸ Distribute App ▸ App Store Connect (or export + Transporter).
4. Confirm no network entitlements; privacy label = no data collected (`PrivacyInfo.xcprivacy`).

## Conventions / gotchas

- All UI + model mutation is `@MainActor`. Keep new state on `PolaroidDocumentModel`.
- `Info.plist` is regenerated by XcodeGen — version/category/min-OS/copyright are set in
  `project.yml` under `targets.Polaroid.info.properties`, not by editing the plist.
- `ScreenshotWatcher` only fires for files named `Screenshot *.png` / `Screen Shot *.png`.
- Caption hard-limit is 60 chars (enforced in model + renderer + editor).
